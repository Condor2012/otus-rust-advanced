# Обработка ошибок — демо к занятию 23

Базовые примитивы обработки ошибок в Rust:

- собственный `enum Error` с реализацией `ToString`;
- `Result<T, E>`: возврат ошибок из функции, разбор через `match` / `if let` / `unwrap_or`;
- `Option<T>`: поиск значения в `HashMap`, отдельный случай `None` для `"admin"`.

```sh
cargo run
```
