# Занятие 15. Многопоточность без страха

Примеры по одноимённой презентации: передача данных между потоками, `Send` и `Sync`, синхронизация и MPSC-каналы. Используется только стандартная библиотека Rust.

## Примеры

- `sharing.rs` — заимствование локальных данных через `thread::scope` и разделение неизменяемой строки через `Arc<String>`.
- `synchronization.rs` — атомарный счётчик, `Arc<Mutex<T>>` для изменяемой строки и `Arc<RwLock<T>>` для настроек.
- `barrier.rs` — четыре потока ждут друг друга на барьере между подготовкой и обработкой.
- `channels.rs` — несколько производителей и один потребитель через `mpsc::channel`, затем ограниченный буфер через `mpsc::sync_channel`.

`Rc` и `RefCell` намеренно не передаются в потоки: они не реализуют необходимые для этого `Send` и `Sync`. Их многопоточные аналоги в примерах — `Arc` и `Mutex`/`RwLock`.

## Запуск

```bash
cargo run --example sharing
cargo run --example synchronization
cargo run --example barrier
cargo run --example channels
```

Порядок сообщений разных потоков может меняться. Итоговый атомарный счётчик равен `400000`, канал передаёт все значения, а ограниченный канал возвращает `[1, 2, 3]`.

## Проверка

```bash
cargo test
cargo clippy --all-targets -- -D warnings
```

Тесты проверяют атомарный счётчик, конвейер на каналах и заимствование локальной строки scoped-потоком.
