# Обработка ошибок, углублённое погружение — демо к занятию 29

Разбор продвинутых сценариев:

- `src/errors.rs` — иерархия ошибок через `thiserror`/`derive_more`: транзакционные ошибки, пользовательские ошибки с дженерик-параметром, конвертация через `From`, признаки `retryable` и `severity_level`;
- `src/main.rs` — сервис пользователей, кастомный panic-hook с логированием, `?` в `main`, замечание про отмену async-операций между await-точками.

Код учебный (не компилируется без доработки — примеры сокращены).
