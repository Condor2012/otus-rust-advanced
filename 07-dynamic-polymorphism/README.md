# Занятие 7. Динамический полиморфизм

Материалы обеих лекций объединены в две демонстрации: гетерогенная коллекция фигур и практика object safety.

## Примеры

- `shapes` — `&dyn Shape`, `Vec<Box<dyn Shape>>`, фабрика `create_shape`, суммарная площадь и поиск самой большой фигуры. Конкретный тип выбирается во время выполнения, вызовы методов проходят через vtable.
- `object_safety` — трейты `Simple`, `ByValue`, `Max` и `MaxGeneric<Rhs>` из практики Rust Playground. Метод `by_value` имеет `where Self: Sized`, поэтому не попадает в vtable и не мешает созданию трейт-объекта. `Max` с параметром `&Self` и `Foo: Clone` не dyn-compatible: первый используется с конкретным типом, второй оставлен в комментарии.

`&dyn Trait` — жирный указатель, содержащий адрес данных и адрес vtable. Его размер зависит от платформы; на 64-битной системе он обычно вдвое больше обычной ссылки.

## Запуск

```bash
cargo run --example shapes
cargo run --example object_safety
cargo test
```

Тесты проверяют гетерогенную коллекцию, фабрику, обработку неизвестного типа и создание допустимых трейт-объектов из практики.
