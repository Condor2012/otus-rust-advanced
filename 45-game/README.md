# Занятие 45. Пример игры

Doodle Jump на чистом Rust: wgpu (рендер) + winit (окно и ввод) + WGSL-шейдер. Без движка и без ассетов — вся графика генерируется прямоугольниками.

## Что показано

- Игровой цикл через `ApplicationHandler` (winit 0.30): `resumed` → создание окна, `about_to_wait` → `request_redraw`, `RedrawRequested` → физика + отрисовка.
- Физика: гравитация, прыжок, перенос по горизонтали (`rem_euclid`), dt с ограничением `MAX_FRAME_DT` (защита от скачков при лагах).
- Бесконечный уровень: платформы догенерируются (`fill_platforms`), уходящие за камеру удаляются (`retain`), детерминированный `SmallRng` с фиксированным сидом.
- Рендер wgpu: surface + adapter + device, render pipeline с вершинным буфером (`bytemuck::Pod`), шейдер на WGSL (`include_str!("shader.wgsl")`), очистка фона, `present`.
- Вершинные данные собираются каждый кадр в CPU-массив прямоугольников (сетка, платформы, игрок с «глазами», линия game over).
- Управление: стрелки или A/D, Esc — выход.

## Запуск

```bash
cargo run   # нужен GPU с поддержкой wgpu (или программный рендер)
```
