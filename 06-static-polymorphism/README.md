# Занятие 6. Статический полиморфизм

Материалы объединяют обе присланные лекции: трейты и дженерики, методы по умолчанию, несколько trait bounds, `where` и мономорфизацию.

## Примеры

- `shapes` — трейт `Shape` с методом `describe` по умолчанию; `Circle`, `Rectangle` и `Triangle`; обобщённые `print_shape`, `get_area` и `compare_shapes`.
- `vec2` — решение практики из Rust Playground: обобщённые реализации `Add` и `Neg` для `Vec2<T>`, а также `length()` для `Vec2<f32>`.

Каждая обобщённая функция компилируется в специализации для использованных конкретных типов. Динамический dispatch здесь не нужен.

## Запуск

```bash
cargo run --example shapes
cargo run --example vec2
cargo test
```

Тесты проверяют площади и периметры фигур, сравнение разных типов через `where`, а также сложение, отрицание и длину `Vec2`.
