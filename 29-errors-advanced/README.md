# Занятие 29. Обработка ошибок углублённо

Конспект/черновик с занятия «Обработка ошибок углублённо».

## Что показано

- `thiserror` 2.x: derive `Error` + `Display` + `From`, варианты с полями `{field}`/`{0}`/`{1}`, `#[from]`, `#[non_exhaustive]`.
- `derive_more`: `Display`/`From` без ручного кода.
- Обобщённый enum ошибок `UserError<MyType>`.
- Классификация ошибок: `retryable()`, `severity_level()` (enum `SeverityLevel`).
- Паника и `std::panic::set_hook` для логирования паник.
- `main() -> Result<(), Box<dyn std::error::Error>>` как «входная точка с `?`».

> Это рабочие заметки с занятия: код местами не компилируется (`logger`, `service`
> вне области видимости, `User.balance` отсутствует) — оставлено как есть, это
> материал для разбора на занятии, а не готовый проект.
