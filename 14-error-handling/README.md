# Занятие 14. Консультация по домашним заданиям

Обработка ошибок на практике: иерархия кастомных ошибок,
оператор `?`, трейт `std::error::Error`, `From`-конверсии.

## Что показано

- Три уровня ошибок: `GetDataError` (верхний), `LoginError`, `DownloadError`.
- Ручная реализация `Display` + `Error` (с `source()`), `#[derive(Debug)]`.
- `From<LoginError>`/`From<DownloadError>` для `GetDataError` — позволяет
  оператору `?` автоматически поднимать ошибки (см. закомментированный
  код `match` — «до» — и цепочку `?` — «после»).
- `process_error`: печать цепочки причин через `Error::source()`.

`dz.md` — текст домашнего задания «Умный дом»: эволюция от паник и
массивов к `Option`, `HashMap`, трейту отчёта и макросу создания комнаты.

## Запуск

```bash
cargo run
```
