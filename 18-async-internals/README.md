# Занятие 18. Асинхронность под капотом

Примеры, показывающие, как устроены async/await в Rust: ленивость футур, состояние-машина, которую генерирует компилятор, и сравнение синхронного и асинхронного чтения файлов.

## Примеры

Сначала сгенерируйте тестовые файлы (по 100 МБ каждый):

```bash
cargo run
```

Затем запускайте примеры:

```bash
cargo run --example tree_files_sync    # синхронное чтение трёх файлов
cargo run --example tree_files_async   # то же через tokio::join! — сравните время
cargo run --example lazy               # футуры ленивы: без await код не выполняется
cargo run --example async1             # ручная StateMachine — то, что генерирует компилятор
```

| Пример | Что демонстрирует |
|---|---|
| `tree_files_sync` | Синхронное последовательное чтение файлов |
| `tree_files_async` | Параллельное чтение через `tokio::join!` |
| `lazy` | Ленивость футур: без `.await` ничего не выполняется |
| `async1` | Как async-код превращается в конечный автомат (`Future`, `poll`, `Pin`) |
