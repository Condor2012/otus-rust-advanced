# Doodle Jump на Rust — пример к занятию 45

Игра «Doodle Jump», написанная на чистом Rust без игровых движков:
окно и ввод — `winit` 0.30, рендер — `wgpu` 30 (WGSL-шейдер),
рендер-петля на `pollster`, вершинные буферы через `bytemuck`,
генерация платформ — `rand` 0.10 (SmallRng, фиксированный seed).

## Запуск

```sh
cargo run
```

Управление: ←/→ или A/D — движение, Esc — выход.

## Как устроено

- Вся сцена собирается в один список прямоугольников (`Game::vertices`):
  сетка, платформы, игрок (с «лапками» и глазами), линия game over.
- Никаких текстур и спрайтов — только цветные квадраты в ортографической
  проекции (480×720, перевод в NDC прямо в вершинах).
- Физика: гравитация 1600 px/s², прыжок 650 px/s, столкновения с платформами
  только при падении; камера следует за игроком, платформы спавнятся сверху
  и удаляются снизу.
- Обертка экрана: игрок, ушедший за левый край, появляется справа.
