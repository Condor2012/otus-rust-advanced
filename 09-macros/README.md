# Занятие 9. Макросы

Декларативные макросы (`macro_rules!`): генерация новых типов по шаблону
на этапе компиляции.

## Что показано

- Макрос `unit!` создаёт тип новой единицы измерения (кортежная структура
  над `f32`) и сразу реализует для неё:
  - `Display` — вывод значения с суффиксом единицы (`1.1m`, `1.1km`);
  - `Add` и `Sub` — арифметику между значениями одного типа.
- Две формы вызова:
  - одиночная: `unit!(Meter, "m");`
  - повторяющаяся с разделителем `;`: `unit! { Second => "s"; Minute => "min"; Hour => "h"; }`
    — внутренняя рекурсия через `$(unit!($name, $suffix);)*`.
- Фрагменты-спецификаторы: `ident`, `literal`, `$(...)*`, необязательный
  завершающий разделитель `$(;)?`.
