# Занятие 13. Практика Rust-разработки #2

Точка входа обработки транзакции: `Payload` → `Order` → отправка через
коннектор (заглушка «message queue»).

## Что показано

- Разделение входного `Payload` (timestamp, ЭЦП, имена сторон, сумма)
  и внутреннего `Order` (отправитель, получатель, сумма).
- Заглушка `Connector::send`, возвращающая `Result<String, String>`.
- Частичное перемещение полей `payload` при сборке `order`
  (после move полей `payload` остаются доступны только `timestamp`/`ecp` —
  поэтому `dbg!` вызывается после частичного move).
- Разбор результата через `if let Ok(...)`.

## Запуск

```bash
cargo test
```
