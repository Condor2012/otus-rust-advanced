# Занятие 20. Бонусное занятие. Практика разработки

Практика по итераторам и коллекциям: три вида итераторов, адаптеры,
`fold` и частотный словарь слов.

## Что показано

- **Три вида итераторов**: `iter()` (по `&T`), `iter_mut()` (по `&mut T`),
  `into_iter()` (по значению, move). Эквивалентность с `for x in &v` /
  `&mut v` / `v`.
- **Адаптеры**: `filter` + `collect`, `map` с мутацией элемента,
  `copied()` / `map(|i| *i)` для перехода от ссылок к значениям.
- **Агрегация**: `sum()` по `&i32` и по значению.
- **`fold`**: частотный словарь слов текста через `HashMap::entry`.
- В закомментированном коде — разбор чётных/нечётных через `fold` и набросок
  enum токенов лексера.

## Запуск

```bash
cargo run
```
