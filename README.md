# otus-rust-advanced

Примеры кода к курсу Otus **«Rust-разработчик. Продвинутый уровень»**.

Каждая папка — материалы одной лекции: рабочий пример и краткое описание.

## Структура

| Лекция | Тема | Код |
|---|---|---|
| — | Примеры добавляются по мере выкладывания лекций | — |

## Как запускать

Каждый пример — отдельный crate:

```bash
cd <папка-лекции>
cargo run
```

или, если это example внутри crate:

```bash
cargo run --example <имя>
```
