# Занятие 4. Владение и типы данных

Демонстрация владения (move/copy), структур, перечислений и трейтов на
примере простого `Person` и HTTP-статусов.

## Что показано

- **Move vs Copy**: `String` передаётся по значению (move), поэтому нужен
  `clone()`; `&str` и `u8` — `Copy`, копируются неявно.
- **Структуры**: объявление `Person`, функции-конструкторы, частичный move
  полей в `teleport_person`.
- **Перечисления**: `Response` с вариантами, включая варианты с данными
  (`String`, `u16`), и разбор через `match`.
- **Трейты**: ручная реализация `Display` для `Person` рядом с
  `#[derive(Debug, Clone)]`.

## Запуск

cargo run
