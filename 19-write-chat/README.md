# Занятие 19. Пишем чат

Асинхронный TCP-чат на tokio: workspace из трёх крейтов —
`protocol` (кадрирование + сообщения), `server` (комната, соединения),
`client` (консольный клиент).

## Три этапа

- `starter/` — заготовка с `todo!()` и TODO-комментариями: код пишется на
  занятии по шагам (шаг 1 — `state.rs`, шаги 2–3 — `conn.rs`, шаг 5 — тесты).
- `middle/` — промежуточное состояние: `Room` реализован (`join`/`leave`/
  `send_to`/`broadcast`/`users`), в `conn.rs` добавлены регистрация ника,
  задача-писатель и уборка при выходе.
- `final/` — итоговая версия: полностью реализован `read_loop` (общий чат,
  приват с ошибкой адресату, список пользователей, повторный Hello),
  клиент с главным циклом `tokio::select!` (stdin + сокет + Ctrl+C),
  graceful shutdown через `TaskTracker` (шаг 4).

## Ключевые идеи

- **Кадрирование**: `[u32 BE — длина][bincode]`, лимит кадра 1 MiB.
- **Разделение писателя и читателя**: сокет делится `into_split`, каждому
  клиенту — свой `mpsc`-канал; рассылка = пройти по мапе отправителей.
- **Рукопожатие с таймаутом**: `Hello` ждём 10 секунд.
- **Graceful shutdown**: `CancellationToken` + `TaskTracker`: `run()`
  возвращается только когда все соединения завершились.
- **Интеграционные тесты** поднимают сервер на `127.0.0.1:0` и ходят в него
  реальными TCP-клиентами.

## Запуск

```bash
cd final   # или starter / middle
cargo run -p netchat-server
cargo run -p netchat-client -- --nick alice
```
